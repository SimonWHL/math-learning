## 简介

数学学习项目是一个基于Python 3.10+的教育性项目，旨在为用户提供数学学习的工具和资源。该项目采用现代化的Python打包标准，使用pyproject.toml进行配置管理，支持开发环境的完整设置和包的分发。

项目的核心特点：
- 支持Python 3.10及以上版本
- 使用现代打包工具setuptools
- 集成pytest测试框架
- 包含Ruff代码格式化工具
- 支持可选开发依赖项

## 依赖安装

### 核心依赖

当前版本的项目没有声明核心依赖项，这意味着项目可以在最小依赖的情况下运行。所有功能都将在需要时动态加载。

### 开发依赖

项目提供了可选的开发依赖项，通过`dev`组提供：

- pytest >= 7.0：用于单元测试和集成测试
- ruff >= 0.1.0：用于代码格式化和静态分析

### 安装开发依赖

要安装开发环境所需的全部依赖，请使用以下命令：

```bash
pip install -e ".[dev]"
```

这将安装：
- 当前项目（以可编辑模式）
- 所有开发依赖项

**重要说明**：可编辑安装允许您在修改源代码后立即看到效果，无需重新安装包。

### 验证安装

安装完成后，可以通过以下方式验证安装是否成功：

```bash
pip list | grep -E "(pytest|ruff)"
```

## 常见问题解决

### Python版本不兼容

**问题**：安装时提示Python版本过低

**解决方案**：
1. 升级到Python 3.10或更高版本
2. 确保PATH环境变量指向正确的Python版本

### 权限错误

**问题**：安装时出现权限错误

**解决方案**：
```bash
# 使用用户安装
pip install --user -e ".[dev]"

# 或者使用管理员权限（Windows）
sudo pip install -e ".[dev]"
```

### 虚拟环境问题

**问题**：虚拟环境无法激活

**解决方案**：
```bash
# 重新创建虚拟环境
rm -rf .venv
python -m venv .venv
# 然后重新激活
```

### 依赖冲突

**问题**：安装依赖时出现冲突

**解决方案**：
```bash
# 清理缓存
pip cache purge

# 强制重新安装
pip install --force-reinstall -e ".[dev]"
```

### 编码问题

**问题**：在Windows上出现编码错误

**解决方案**：
```bash
# 设置Python编码
set PYTHONIOENCODING=utf-8
set PYTHONUTF8=1
```

## 故障排除指南

### 安装问题

**问题**：pip版本过旧

**解决方案**：
```bash
python -m pip install --upgrade pip
```

**问题**：网络连接问题

**解决方案**：
```bash
# 使用国内镜像源
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple/ -e ".[dev]"
```

### 构建问题

**问题**：构建失败

**解决方案**：
```bash
# 清理构建缓存
rm -rf build/ dist/ *.egg-info/

# 重新安装构建工具
pip install --upgrade setuptools wheel

# 重新安装项目
pip install -e ".[dev]"
```

### 测试问题

**问题**：测试无法运行

**解决方案**：
```bash
# 检查pytest配置
pytest --collect-only

# 运行单个测试文件
pytest tests/test_example.py -v
```

### 版本控制问题

**问题**：Git操作失败

**解决方案**：
```bash
# 检查Git状态
git status

# 更新子模块
git submodule update --init --recursive
```
