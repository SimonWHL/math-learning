## 简介

数学学习项目是一个现代化的教育工具项目，基于Python 3.10+构建，提供100以内加减法口算题的生成和Word文档导出功能。项目采用前后端分离架构，后端使用FastAPI提供RESTful API，前端使用React/Vite构建用户界面。

项目的核心特点：
- 支持Python 3.10及以上版本
- 前后端分离架构，现代化开发体验
- Docker容器化部署支持
- 实时口算题生成和Word文档导出
- 响应式Web界面设计

## 基本使用示例

### 后端API使用

```python
# 直接调用Python函数
from math_learning.core.generator import generate_problems, Operation

# 生成10个加减混合题目
problems = generate_problems(
    count=10,
    operations=[Operation.ADD, Operation.SUBTRACT],
    seed=42
)

for problem in problems:
    print(f"{problem.expression} = {problem.answer}")
```

### Web界面使用

1. 启动开发服务器：
```bash
# 后端
uvicorn src/math_learning/web/main:app --reload

# 前端
cd frontend
npm run dev
```

2. 访问 http://localhost:5173
3. 配置题目数量和运算类型
4. 点击生成按钮查看结果
5. 点击下载按钮获取Word文档

### API接口使用

```python
# 使用Python requests库
import requests
import json

# 生成题目
response = requests.post(
    'http://localhost:8000/api/generate',
    json={
        'count': 20,
        'operations': ['add', 'subtract'],
        'seed': 123
    }
)

data = response.json()
print(f"生成了 {data['count']} 个题目")

# 下载Word文档
response = requests.post(
    'http://localhost:8000/api/download',
    json={'count': 10}
)

with open('math_problems.docx', 'wb') as f:
    f.write(response.content)
```

## 常见问题解决

### Python环境问题

**问题**：Python版本不兼容

**解决方案**：
1. 升级到Python 3.10或更高版本
2. 使用pyenv管理多个Python版本
3. 确保PATH环境变量指向正确的Python版本

### 依赖安装问题

**问题**：pip安装失败

**解决方案**：
```bash
# 清理pip缓存
pip cache purge

# 使用国内镜像源
pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple/ .

# 强制重新安装
pip install --force-reinstall -e ".[dev]"
```

### 前端依赖问题

**问题**：npm安装失败或依赖冲突

**解决方案**：
```bash
# 清理node_modules
rm -rf frontend/node_modules

# 清理npm缓存
npm cache clean --force

# 使用pnpm替代npm（推荐）
npm install -g pnpm
cd frontend
pnpm install
```

### Docker构建问题

**问题**：Docker构建失败

**解决方案**：
```bash
# 清理Docker构建缓存
docker builder prune

# 检查Dockerfile语法
docker build --no-cache -t math-learning:latest .

# 查看详细构建日志
docker build -t math-learning:latest --progress=plain .
```

### 端口冲突问题

**问题**：端口8000被占用

**解决方案**：
```bash
# 查找占用8000端口的进程
lsof -i :8000

# 修改docker-compose端口映射
sed -i 's/8000:8000/8001:8000/g' docker-compose.yml

# 或者停止占用进程
kill -9 $(lsof -t -i :8000)
```

### 权限问题

**问题**：Docker权限不足

**解决方案**：
```bash
# 将用户添加到docker组
sudo usermod -aG docker $USER

# 重新登录或执行
newgrp docker

# 或使用sudo（不推荐）
sudo docker build -t math-learning:latest .
```
