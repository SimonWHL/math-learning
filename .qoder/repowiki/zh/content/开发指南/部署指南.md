## 简介

数学学习项目是一个基于 FastAPI 和 React 的现代化 Web 应用，专门用于生成 100 以内的加减法口算练习题。该应用支持在线预览和 Word 文档下载功能，采用前后端分离架构，通过 Docker 进行容器化部署。

### 开发环境启动步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd math-learning
```

2. **安装后端依赖**
```bash
pip install -e .
```

3. **启动后端服务**
```bash
uvicorn math_learning.web.main:app --reload --host 0.0.0.0 --port 8000
```

4. **安装前端依赖**
```bash
cd frontend
npm install
```

5. **启动前端开发服务器**
```bash
npm run dev
```


## 故障排除

### 常见问题及解决方案

```mermaid
flowchart TD
Error[出现错误] --> CheckPort{端口占用}
CheckPort --> |是| KillProcess[终止占用进程]
CheckPort --> |否| CheckDeps[检查依赖]
CheckDeps --> InstallDeps[重新安装依赖]
InstallDeps --> Restart[重启服务]
KillProcess --> Restart
Restart --> Test[测试连接]
Test --> Success[问题解决]
```

### 错误诊断流程

1. **服务启动失败**
   - 检查端口是否被占用
   - 验证 Python 版本兼容性
   - 确认依赖包安装完整

2. **API 请求失败**
   - 检查 CORS 配置
   - 验证请求格式正确性
   - 查看服务器日志

3. **前端无法访问**
   - 确认代理配置正确
   - 检查防火墙设置
   - 验证网络连接

### 版本管理

1. **语义化版本控制**
   - 主版本号：不兼容的 API 变更
   - 次版本号：向后兼容的功能新增
   - 修订号：向后兼容的问题修正

2. **分支策略**
   - main 分支：稳定版本
   - develop 分支：开发版本
   - feature/* 分支：功能开发
   - hotfix/* 分支：紧急修复

1. **数据备份**
